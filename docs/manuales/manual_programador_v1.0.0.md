# Manual del Programador v1.0.0

## Estructuras (Struct) y Operador Flecha (->)

### Definición de Struct

Una estructura es un tipo de dato compuesto que permite agrupar variables de diferentes tipos bajo un solo nombre. Se utiliza para modelar entidades del mundo real con múltiples atributos.

### Operador Flecha (->)

El operador flecha se utiliza para acceder a los miembros de una estructura a través de un puntero. Es una forma simplificada de la combinación de desreferenciación y acceso al miembro.

### Relación con la Memoria RAM

Cuando se declara una estructura, se asigna un bloque contiguo de memoria que contiene todos sus miembros. Los punteros almacenan la dirección de inicio de este bloque, permitiendo acceder a los datos sin copiarlos.

### Direcciones Hexadecimales

Las direcciones de memoria se representan típicamente en formato hexadecimal (base 16), utilizando el prefijo 0x. Cada byte de memoria tiene una dirección única que identifica su ubicación en la RAM.
