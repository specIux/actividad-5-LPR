### Descripción del Modelo

Este proyecto tiene como objetivo comprender y aplicar el modelado de datos mediante estructuras (struct) y punteros en C++. Se explora cómo la memoria RAM almacena y gestiona los datos, utilizando direcciones hexadecimales para visualizar la ubicación de las variables en memoria.

El programa principal demuestra el uso del operador flecha (`->`) para acceder a miembros de estructuras a través de punteros, así como la relación entre variables y sus direcciones de memoria.
